# ax-kit 맥 데스크톱 앱

이 맥에서 도는 ax-kit 비서와 이야기하는 맥 앱입니다. Tauri 2(Rust) + React + TypeScript, macOS 전용.
서버는 [axkit](https://github.com/myungkeun02/axkit) 레포(앱 프로토콜: `docs/APP-PROTOCOL.md`), 아이폰 앱은 `ax-kit-ios` 레포에 있어요.
화면과 규칙은 아이폰 앱과 같습니다: 회색 바탕에 흰 카드, 버튼 세 가지(채운 파랑 / 연한 파랑 / 연한 빨강), 이모지 없음, 쉬운 한국어, 밝은·어두운 모드.

맥답게 만들었어요: 왼쪽 사이드바에 모든 곳이 묶음별로 다 있고(더보기 없음), 넓은 창에서는 목록 | 내용, 대화 | 결재처럼 나란히 보여요.

| 사이드바 | 하는 일 |
|---|---|

### 위젯

메뉴 막대의 ax-kit 아이콘을 누르면 아이콘 아래로 작은 창이 내려와요(다른 곳을 누르면 닫혀요). 오늘 남은 일정·할 일(`views/today`), 결재 대기 수, 최근 알림 두 개, 비서 상태("비서가 생각하는 중…"), 비서에게 한 줄 보내기 칸이 있고, 답이 오면 그 아래 한 줄로 보여요. 줄을 누르면 앱이 그 화면(결재·캘린더·비서)으로 열려요. **고정**을 누르면 화면 위에 계속 떠 있고(모든 데스크톱 공간에서), 위쪽을 끌어 옮길 수 있어요. 아이콘 오른쪽 클릭 메뉴에도 '위젯 열기'가 있어요.

위젯은 같은 웹 페이지를 `widget` 창으로 하나 더 띄운 것이에요. 서버 연결은 앱 창이 열어 둔 스트림 하나를 같이 써요(`stream_ensure`). 토큰은 여전히 Rust에만 있어요.

왜 이 방식인지:

| 방식 | 장점 | 부담 |
|---|---|---|
| 맥 데스크톱·알림 센터 위젯(WidgetKit) | 맥 기본 위젯 자리에 놓여요 | Tauri가 지원하지 않아 Swift 위젯 확장 타깃을 따로 붙여야 해요. App Group 공유와 정식 서명(Apple 개발자 프로그램)이 있어야 맥이 위젯을 불러요. 지금 같은 임시 서명(`-`)으로는 위젯 목록에 나오지 않아요. 위젯은 스스로 네트워크를 못 써서(타임라인 갱신 제한) 실시간 "생각하는 중…"도 어려워요. |
| 메뉴 막대 아이콘 팝오버 | Tauri 2가 그대로 지원해요(트레이 아이콘 + 창). 서명 그대로. 이미 아이콘이 있어요 | 누를 때만 보여요 |
| 항상 위에 뜨는 작은 창 | 늘 보여요. Tauri 2가 그대로 지원해요 | 화면을 차지해요 |

그래서 2와 3을 한 창으로 만들었어요: 평소엔 메뉴 막대에서 내려오고, 고정하면 떠 있는 창이 돼요. WidgetKit은 정식 서명을 갖춘 뒤에 다시 볼 일이에요.

비서가 보낸 문서(pdf·오피스·한글·txt·zip)는 대화에 파일 줄로 와요. 누르면 다운로드 폴더에 저장하고 훑어보기(Quick Look)로 보여 줘요(실행하지 않음). 맥은 하루만 보관해서, 지나면 "하루가 지나 지워졌어요"라고 나와요.

봇 말에 마우스를 올리거나 오른쪽 클릭: 좋아요 · 이런 거 더 / 별로예요 · 이런 거 덜 / 복사(방마다 가장 최근 봇 말에는 늘 보임). 대화 입력칸의 ＋ 또는 끌어다 놓기로 사진·파일(12MB까지)을 비서에게 보내요.
읽기만 하는 알림 채널(결재·브리핑·장애·로그·알림 방)은 서버가 보내도 사이드바에 넣지 않아요. 서버가 보낸 글의 디스코드 문법·내부 id·메타데이터 줄은 앱이 정리해서 보여요(src/core/chatText.ts).

어디서든 **⌘K**로 아무 곳(팀 이름도)이나 찾아 가요.

서버가 보내 주는 목록(봇, 뷰, 선택지, 새 기능 화면)으로 그리므로 서버에 없는 기능의 화면은 숨겨지고, 새 봇·기능은 앱 업데이트 없이 나타납니다.

## 처음 쓰는 법

1. `ax-kit.app`을 /Applications에 넣고 열어요(정식 서명 전이라 처음엔 오른쪽 클릭 → 열기). 창을 닫아도 메뉴 막대 아이콘에 남아요. 끝내려면 ⌘Q.
2. 메뉴 막대 아이콘을 누르면 **위젯**이 내려와요(오늘 일정·할 일, 결재 대기, 최근 알림, 비서 상태, 한 줄 보내기).
3. 첫 화면에서 연결할 비서를 골라요.
   - **이 맥의 비서**: 이 맥에서 ax-kit 서버가 돌면 짝 맞추기 없이 바로 붙어요(아래 "이 맥 연결").
   - **다른 맥의 비서에 연결**: 작업용 맥북에서 집의 맥미니 비서를 쓸 때(아래 "다른 맥 연결").
4. 앱 안 **맥 › 도움말**에 같은 내용과 연결이 안 될 때 볼 것이 있어요.

## 다른 맥 연결 (작업용 맥북 → 집의 맥미니, Tailscale)

1. 두 맥 모두 Tailscale을 켜고 같은 계정으로 로그인해요. 맥미니의 ax-kit는 Tailscale 주소(보통 `https://<맥미니>.<tailnet>.ts.net`)로 열려 있어야 해요.
2. 맥미니에서 `ax-kit phone pair --app --platform desktop --name "작업용 맥북"`.
3. 나온 `링크: axkit://pair?u=…&n=…&c=…`를 맥북 앱의 '다른 맥의 비서에 연결'(첫 화면, 또는 설정 및 연결)에 붙여 넣고 '연결하기'. 링크 대신 주소·코드·연결 id를 직접 넣어도 돼요. 코드는 10분, 한 번만.

앱은 코드를 `POST {주소}/m/p/<연결 id>/app`로 한 번 보내 기기 토큰을 받고(APP-PROTOCOL §2), 토큰은 **맥의 키체인에만** 둬요(`src-tauri/src/remote.rs`, 웹뷰에는 안 넘어감). 짝 맞출 때 닿은 주소를 계속 써요. https는 어디든, http는 Tailscale(100.64/10)·집 안·이 맥 주소만 받아요. 80일마다 토큰을 새로 받고(`POST rotate`), 설정 및 연결의 '연결 끊기'는 `POST unpair`로 맥미니에서도 바로 지워요. 임시 서명 앱이라 업데이트 뒤 처음 열 때 키체인이 허락을 물을 수 있어요('항상 허용').

연결이 안 될 때: 두 맥의 Tailscale이 켜져 있는지, 같은 계정인지, 맥미니가 잠들지 않았는지, `tailscale ping <맥미니>`가 되는지 봐요. "코드가 지났어요"면 맥미니에서 짝 맞추기를 다시 해요. "연결을 받지 않아요"면 맥미니에서 이 기기를 지웠거나 토큰이 바뀐 거라 다시 짝 맞춰요.

창 없이 실제 서버와 맞춰 보기: `cargo run --example probe -- --pair "<링크>"`(토큰은 메모리에만, 끝나면 연결 끊기까지 해요).

## 이 맥 연결 (짝 맞추기 없음)

ax-kit 서버는 켜질 때마다 새 토큰을 `~/.ax-kit/desktop.token`(`{"v":1,"baseUrl":"http://127.0.0.1:47617","token":"…"}`)에 씁니다. 앱은:

- 이 파일을 **Rust 쪽에서만** 읽고, 모든 요청에 토큰을 붙입니다. 화면(웹뷰)에는 토큰이 넘어가지 않아요(`src-tauri/src/lib.rs`의 명령만 노출).
- 주소가 이 맥(127.0.0.1·::1·localhost)이 아니면 붙지 않습니다.
- 401이 오면 파일을 다시 읽고 한 번 더 해 봅니다(서버 재시작 = 토큰 바뀜, 실제 서버로 확인). 파일이 없으면 "ax-kit를 기다리고 있어요" 화면을 보여요.
- 실시간 스트림(`GET stream`, SSE)도 Rust가 열어 두고 이벤트만 화면에 넘깁니다. 끊기면 2초부터 60초까지 늘려 가며 다시 붙고(`Last-Event-ID`), 붙을 때마다 `events?after=`로 빈 곳을 채워요. 같은 이벤트가 두 번 와도 한 번만 보입니다.
- 다른 파일을 쓰려면 `AXKIT_TOKEN_FILE=/경로/desktop.token`.
- 날짜·시각은 서버가 알려 주는 비서의 시간대(`status.assistant.timezone`, 기본 서울)로 그려요.

## 빌드와 실행

필요: Node 20+, Rust(stable). 이 맥에는 Homebrew `rustup`으로 설치돼 있어요 — 터미널에서 `cargo`가 안 보이면 먼저:

```bash
export PATH=/opt/homebrew/opt/rustup/bin:$PATH
```

```bash
npm install
```

진짜 ax-kit 서버(이 맥에서 켜져 있어야 함)와:

```bash
npm run tauri dev
```

개발용 가짜 맥과. `dev/desktop-mock.mjs`가 아이폰 레포의 가짜 맥(`~/dev/ax-kit-ios/dev/mock-server.mjs`, 옆에 있어야 함)을 안쪽(47796)에서 띄우고, 데스크톱만 쓰는 것(장소 좌표·길찾기·통계)을 더해 47795에서 받아요. 터미널 하나에서:

```bash
npm run mock
```

다른 터미널에서:

```bash
AXKIT_DEV_MOCK=http://127.0.0.1:47795 npm run tauri dev
```

가짜 맥은 짝 맞추기 토큰을 쓰므로, 개발 빌드는 그 주소로 짝 맞추기(번호 123456)를 해서 붙습니다. 앱 안의 더보기 › 설정 및 연결 › **개발용**에서도 바꿀 수 있어요(개발 빌드에만 보임).
사람 카드와 받아쓰기 목: `curl -s 'http://127.0.0.1:47795/dev/people?empty=1'`(카드 비우기, 없이 부르면 되돌림), `curl -s 'http://127.0.0.1:47795/dev/dictation?fail=503'`(받아쓰기 실패 흉내, 없이 부르면 되돌림). 가짜 받아쓰기는 소리를 듣지 않고 정해진 문장을 돌려줘요.
가짜 맥에서 일을 만들어 보기: `curl -s http://127.0.0.1:47796/dev/card`(새 결재), `curl -s 'http://127.0.0.1:47796/dev/notice?text=hi'`.

Tauri 없이 화면만 브라우저에서 보기(가짜 맥과, Vite가 `/m/`을 47795로 넘겨 줌):

```bash
npm run dev
```

그리고 http://127.0.0.1:1420 을 엽니다.

테스트:

```bash
npm test
```

```bash
cd src-tauri && cargo test
```

`npm test`는 `~/dev/ax-kit-ios/dev/mock-server.mjs`가 있으면 가짜 맥을 47791에 띄워 프로토콜 클라이언트를 실제로 맞춰 봅니다(없으면 그 부분만 건너뜀).

진짜 ax-kit 서버와 맞춰 보기(서버가 이 맥에서 켜져 있을 때, 창 없이):

`AXKIT_PROJECTS_SAVE=1`을 붙이면 프로젝트 가져오기의 저장도 시험해요. 고른 목록을 잠깐 바꿨다가 되돌려 놓아요.
`AXKIT_TEAMPLAN=1`을 붙이면 팀 구조 제안을 고쳐 저장하고 실제로 만들어요. 시험용 서버에서만 쓰세요.

cd src-tauri && AXKIT_TOKEN_FILE=~/.ax-kit/desktop.token cargo run --example probe

## 설치와 업데이트

이 맥에서 빌드해서 `/Applications/ax-kit.app`에 넣어요(최신 코드 받기 → 빌드 → 바꿔 넣기 → 열기). 새 버전도 같은 명령이에요:

```bash
npm run install-app
```

`-- --no-pull`(코드 받기 건너뛰기), `-- --no-open`(설치만). 설치된 버전과 커밋은 설정 및 연결 › 연결 방법 › 앱 버전에 보여요.

- **임시 서명(ad-hoc)**: Apple 개발자 인증서 없이 서명해요. 이 맥에서 쓰기엔 충분하고, 다른 맥에서는 처음에 우클릭 › 열기.
  새로 빌드하면 macOS가 마이크·알림 허락을 다시 물을 수 있어요. 개발자 인증서가 생기면 `tauri.conf.json`의 `bundle.macOS.signingIdentity`만 바꾸면 돼요.
- 마이크: 녹음할 때 macOS가 한 번 물어요(`Entitlements.plist`의 audio-input, `Info.plist`의 설명).
- 창을 닫아도 앱은 **메뉴 막대**에 남아 결재 수를 보여 주고 알림을 받아요(아이콘 옆 숫자, Dock 배지). 끝내려면 ⌘Q 또는 메뉴 막대 › 끝내기.
- **맥 알림**: 창이 앞에 없을 때 새 결재, 비서의 말, 팀이 끝냈거나 막힌 일. 1분에 3개까지, 나머지는 한 줄로 모아요. 설정 및 연결 › 알림에서 끄고 켜고 시험해 볼 수 있어요.

- 서버에 바라는 것은 모두 들어갔어요(ax-kit main 8ae64aa까지, `PROTOCOL-REQUESTS.md`).
- 지도·길찾기는 맥 서버에 한국 생활 묶음과 카카오·ODsay 키가 있어야 켜져요(`ax-kit setup`). 처음엔 집 위치를 정해 달라고 나와요.
- 실제 마이크로 말해서 회의록까지 가는 것은 사람이 녹음해 봐야 해요. 녹음 파일 올리기는 실제 서버로 확인했어요(받아쓰기 엔진이 없는 시험 서버라 '정리하지 못했어요'로 끝남).
- 정식 서명·공증(Apple 개발자 프로그램 필요).


### 앱 업데이트 (§32, 정식 서명 없이)

- 빌드 번호는 이 저장소의 커밋 수(`git rev-list --count HEAD`)예요. Vite가 `__APP_BUILD__`로 앱에 넣고, 설정의 앱 버전에도 보여요. 비서 맥은 같은 수를 `desktop.build`로 기록해요.
- 서버가 `app-updates` 기능을 알리면 연결할 때와 하루 한 번 `views/app-updates`를 읽어요. 더 큰 빌드가 있으면 화면 위에 '새 버전이 있어요 · 바꾸기', 설정 › 앱 업데이트에도 바꾸기.
- 바꾸기(`src-tauri/src/update.rs`): 기기 토큰으로 `app-updates/desktop.zip`을 받아 sha256 확인 → `ditto`로 풀기 → 번들 id(`dev.axkit.desktop`)·서명·쓰기 권한 확인 → 셸 도우미가 앱이 닫히길 기다렸다가 `/Applications/ax-kit.app`을 바꾸고(실패하면 옛 앱을 되돌림) quarantine을 지운 뒤 다시 열어요. 그 전에 실패하면 쉬운 말로 알리고 지금 앱은 그대로예요. 연결(키체인·앱 데이터)은 건드리지 않아요.
- **GitHub 공개 릴리스**에서도 찾아요(비서 맥과 따로, 연결이 없어도): 앱이 켜질 때·연결할 때·하루 한 번 `https://github.com/myungkeun02/axkit-desktop/releases/latest/download/ax-kit-desktop.json`(`{build, versionName, builtAt, sha256, size}`)을 Rust가 읽어요. 더 큰 빌드면 화면 위 '새 버전 있어요 · 업데이트'. 업데이트를 누르면 json을 다시 읽고 `ax-kit-desktop.zip`을 받아 **크기**와 sha256을 맞춘 뒤 위와 같은 확인·바꾸기(quarantine 지우기 포함). 비서 맥과 GitHub 둘 다 있으면 빌드가 큰 쪽, 같으면 비서 맥.
- 릴리스 만들기: `RUSTFLAGS="--remap-path-prefix=$HOME=~" npm run package-zip` → `release/ax-kit-desktop.zip`, 같은 빌드 번호로 json을 만들어 `gh release create v0.1.<빌드> -R myungkeun02/axkit-desktop release/ax-kit-desktop.zip release/ax-kit-desktop.json`.
- 시험: `cargo run --example probe -- --update "<axkit://pair 링크>" <임시 폴더>`(받기·확인·풀기·바꾸기를 그 폴더에), 가짜 맥은 `curl -s 'http://127.0.0.1:47795/dev/update?build=999'`(되돌리기는 `/dev/update`). GitHub 쪽은 `/dev/update?release=999`(미리보기는 `/m/dev/release.json`을 읽어요).

### 설치 스크립트로 깔고 바로 연결하기 (axkit:// 링크)

- 앱 번들: `ax-kit.app` (번들 id `dev.axkit.desktop`), 실행 파일 `ax-kit.app/Contents/MacOS/ax-kit-desktop`. 임시(adhoc) 서명.
- 배포용 zip: `npm run package-zip` → `release/ax-kit-desktop.zip` (`ditto -c -k --keepParent`, 안에 `ax-kit.app`). 빌드는 스크립트 안에서 `/tmp/huyeor-heavy-build.lock`을 잡으니 다시 lockf로 감싸지 마세요. `dist/`가 아닌 건 Vite가 빌드할 때마다 `dist/`를 비우기 때문이에요.
- 설치 스크립트 순서: zip 풀기 → `/Applications/ax-kit.app`에 넣기 → `xattr -dr com.apple.quarantine /Applications/ax-kit.app` → `open /Applications/ax-kit.app` → `open 'axkit://pair?u=…&n=…&c=…'`.
- 앱은 `axkit` URL 스킴을 등록해요(Info.plist `CFBundleURLTypes`). 꺼져 있다가 링크로 켜져도, 켜져 있을 때 받아도 같은 링크 처리: `axkit://pair`만, 주소(u)는 https만, 연결 id(n)·6자리 코드(c) 형식 검사.
- 아직 연결된 비서가 없으면 바로 짝 맞추고 "연결됐어요". 이미 다른 비서와 이야기하고 있으면 "이 맥의 비서를 <주소>로 바꿀까요?"를 한 번 물어요(아무 링크나 비서를 옮기지 못하게).
- 미리보기에서 시험: `http://127.0.0.1:1420/?pairlink=<url 인코딩한 링크>`.
